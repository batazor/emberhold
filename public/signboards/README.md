# MiiruArt signboards

The game uses two modified models from MiiruArt's
[12 Stylized Low Poly Signboard](https://miiruart.itch.io/12-low-poly-stylized-signboard)
pack:

- `miiru-signboard-06.glb` — road directions;
- `miiru-signboard-05.glb` — player-written signs.

Their embedded textures were resized from 4K to 1K for the web build. Geometry
and materials otherwise come from the original pack. See `LICENSE.miiru.txt`.
