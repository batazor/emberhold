# Карнавальное колесо (спин-модель + логика прокрутки)

Референс, забранный целиком с CodePen: https://codepen.io/jaredstanley/full/LEEORoB
(автор Jared Stanley). Код и ассеты лежат локально, внешних зависимостей —
только three.js и lottie-web с esm.sh в `main.js`.

Открыть: `index.html` через любой статический сервер (модульный скрипт,
с file:// не заведётся).

## Что внутри

- `assets/carnival.glb` — сцена колеса (без Draco). Ключевые ноды по именам:
  `wheel` (барабан), `lever` (рычаг), `hitarea` (невидимый меш под рейкаст),
  `sign_swing` (качающаяся табличка «pull»), `result_panel` (панель результата,
  анимация `result_panelAction` в GLB), `num1..num10` (цифры результата),
  `shadow` (плоскость тени).
- `assets/baked.jpg`, `wheel.jpg`, `shadow.png` — запечённые текстуры,
  всё на MeshBasicMaterial, света в сцене нет.
- `assets/crnvlintro.json`, `intro-bg.jpg` — Lottie-заставка до входа.

## Как работает прокрутка (main.js)

1. Тянущий жест: на pointerdown рейкаст в `hitarea`; если попал — OrbitControls
   отключается и начинается драг. Пока палец идёт **вниз**, копится
   `dragDistance`; рычаг наклоняется `lever.rotation.x = min(2, dist/100 + 1)`,
   и в прирост скорости добавляется `inc += r/100` (потолок `inc < 0.4`).
2. На отпускании рычаг возвращается в `rotation.x = 1`.
3. В `tick()` колесо крутится накоплением: `speed += inc; wheel.rotation.z = speed`,
   а `inc -= 0.001` за кадр — линейное затухание до нуля, дальше колесо стоит.
4. Результат — из конечного угла: `rad = (rotation.z * 180/π) % 360;
   answer = floor(1 + rad/36)` (10 секторов по 36°). Показывается `num{answer}`
   и панель результата проигрывается вперёд (`timeScale = 1`); при новом спине —
   назад (`timeScale = -1`).
5. Камера на входе доезжает до цели покадровым easeOutCubic (~100 итераций),
   easing-функции написаны руками (`easeOutCubic`, `easeInOutCubic`).

## Что взять для наших механик

- Схема «жест → накопленный импульс → затухание → результат из угла» — готовая
  основа для колеса фортуны/лотереи у торговца или ярмарки.
- Рейкаст в отдельный невидимый hitarea-меш вместо точной геометрии рычага.
- Реверсивная анимация панели результата одним clipAction (timeScale ±1).
