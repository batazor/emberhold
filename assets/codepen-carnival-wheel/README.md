# Карнавальное колесо (спин-модель + логика прокрутки)

Референс, забранный с CodePen: https://codepen.io/jaredstanley/full/LEEORoB
(автор Jared Stanley), и подрезанный под нас: оставлен только сам спин —
Lottie-заставка, шатёр, прилавок и прочие фоновые постройки убраны,
вместо них колесо стоит на лугу стартового экрана игры.

Открыть: `index.html` через vite dev проекта
(`localhost:PORT/assets/codepen-carnival-wheel/index.html`) — three берётся
из node_modules, трава — из `src/render/fluffyGrass.ts`, её ассеты —
из `public/grass/`.

## Что внутри

- `assets/carnival.glb` — сцена целиком (без Draco). В демо показывается
  белый список нод: `wheel`, `wheel_base` (опоры и ступени), `lever`,
  `hitarea` (невидимый меш под рейкаст), `sign_swing` (табличка «pull»),
  `result_panel` (+ `num1..num10`), стрелка и вывеска SPIN. Остальное —
  шатёр, прилавок, попкорн, занавес — спрятано, но лежит в GLB.
  Внимание: GLTFLoader заменяет пробелы в именах нод на подчёркивания
  (`wheel base` → `wheel_base`).
- `assets/baked.jpg`, `wheel.jpg`, `shadow.png` — запечённые текстуры,
  всё на MeshBasicMaterial, свет в демо нужен только траве и земле.

## Как работает прокрутка (main.js)

1. Тянущий жест: на pointerdown рейкаст в `hitarea`; если попал — OrbitControls
   отключается и начинается драг. Пока палец идёт **вниз**, копится
   `dragDistance`; рычаг наклоняется `lever.rotation.x = min(2, dist/100 + 1)`,
   и в прирост скорости добавляется `inc += r/100` (потолок `inc < 0.4`).
2. На отпускании рычаг возвращается в `rotation.x = 1`, и к рывку добавляется
   случайная добавка `0.05 + rand()*0.35` — без неё затухание фиксированное
   и колесо всегда останавливалось на одном секторе (наша правка; стартовый
   автоспин рандомизирован так же).
3. В `tick()` колесо крутится накоплением: `speed += inc; wheel.rotation.z = speed`,
   а `inc -= 0.001` за кадр — линейное затухание до нуля, дальше колесо стоит.
4. Результат — из конечного угла: `rad = (rotation.z * 180/π) % 360;
   answer = floor(1 + rad/36)` (10 секторов по 36°). Показывается `num{answer}`
   и панель результата проигрывается вперёд (`timeScale = 1`); при новом спине —
   назад (`timeScale = -1`).
5. Камера на входе доезжает до цели покадровым easeOutCubic (~100 итераций),
   easing-функции написаны руками (`easeOutCubic`, `easeInOutCubic`).

## Фон: луг стартового экрана

Небо и туман — цвета из `src/render/scene.ts` / `titleView.ts`; земля —
круг Lambert, поднятый к подошве основания (модель чуть притоплена, иначе
читалась парящей); трава — `FluffyGrass` с `reject`-прогалиной по подошве
(в сторону камеры шире — она стоит низко, и ближние травинки ложатся
в кадре на модель). `FluffyGrass` грузит ассеты по пути `grass/…` —
демо поворачивает его к `public/` через `DefaultLoadingManager.setURLModifier`.

## Что взять для наших механик

- Схема «жест → накопленный импульс → затухание → результат из угла» — готовая
  основа для колеса фортуны/лотереи у торговца или ярмарки.
- Рейкаст в отдельный невидимый hitarea-меш вместо точной геометрии рычага.
- Реверсивная анимация панели результата одним clipAction (timeScale ±1).
