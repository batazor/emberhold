Мир: карта, которая сама себя обеспечивает

Третья петля — та, что живёт днями. Восемь кадров выбора локации и рабочая модель ленивой симуляции: кланы-боты не тикают, их состояние вычисляется в момент взгляда. Правило, из которого выведено остальное: карта — это не контент, а причина выбирать. Если локации равноценны, карта превращается в список кнопок, и её можно вырезать целиком.

Статус документа. §4 задаёт только принципы: истощение, диегетические боты, чистая функция состояния. Все числа ниже — предложение этого документа, а не решение из DESIGN.md, и подлежат проверке замерами. Помечены по месту.

Часть I

Раскадровка

Карта открывается на второй день — по §21 не раньше, чем локации начали надоедать. Это принципиально: карта отвечает на скуку, и если показать её до того, как скука появилась, она читается как ещё один экран меню.

Часть II

Боты не тикают: модель целиком на этой странице

Ниже — не картинка мира, а сам мир: двадцать локаций и четыре клана, выведенные из f(clanId, seed, t). Двиньте время — состояние пересчитывается с нуля на каждый кадр. Фонового процесса нет, истории нет, записей нет. Прыжок на пятый день стоит ровно столько же, сколько шаг на минуту вперёд, и это же свойство даёт воспроизводимость багов.

Толщина кольца — ярус локации (0–3). Метка сбоку — фракция, которая работает здесь прямо сейчас.

// вся симуляция мира — три чистые функции, ни одного таймера

function clanState(clanId, seed, t) {
  const r = mulberry32(hash(seed, clanId));
  const pace  = 0.7 + r() * 0.6;              // характер клана: медленный / жадный
  const level = 1 + Math.floor(Math.log2(1 + t / (90 * 60e3) * pace));
  const slots = Math.min(4, 1 + Math.floor(level / 2));
  // какие локации заняты — выводится из времени, а не хранится
  const shift = Math.floor(t / (40 * 60e3));   // клан переезжает раз в 40 минут
  return { level, nodes: pick(nodeCount, slots, hash(seed, clanId, shift)) };
}

function richness(nodeId, seed, t, visits) {   // visits — дельты игрока, единственное, что хранится
  const drain = clansOn(nodeId, seed, t) + visits(nodeId, t);
  return clamp(3 - drain + Math.floor(elapsedSince(nodeId, t) / (2 * 3600e3)), 0, 3);
}

Почему не тикающий цикл

Тысяча ботов стоит столько же, сколько один: считается только то, на что игрок смотрит. Нажмите «1000 кланов» — на карте станет тесно, а время пересчёта почти не изменится.

Что всё-таки хранится

Только дельты взаимодействий: куда игрок ходил и когда. Остальное — сид и часы. Отсюда же и серверная валидация из §6: сервер повторяет ту же функцию и сверяет результат.

Цена решения

Мир нельзя «сломать» событием — прошлого у него нет. Любое реальное последствие обязано лечь в дельты, поэтому каждая новая механика мира стоит поля в сохранении. Это дисциплинирующее ограничение, а не помеха.

Часть III

Истощение: числа, которые предлагает документ

Конкуренция без PvP держится на одном ресурсе — богатстве локации. Оно тратится любым посещением, чужим или своим, и восстанавливается временем. Игрок не воюет с кланом, он приходит после него.

ВеличинаЗначениеИз чего следует
Богатство локации3 захода Сессия — 15 минут и 3–5 вылазок (§21). Одна локация не должна закрывать всю сессию, иначе карта не нужна.

Проверяемое условие, аналогичное §11.9: в любой момент времени игроку доступны минимум три локации с богатством ≥ 2 на его ярусах. Если условие нарушается, карта учит ждать вместо того, чтобы учить выбирать, — а ожидание игрок проводит вне игры. Условие считается той же функцией, без запуска клиента.

Что этот документ фиксирует

Решено

  • Карта — экран сравнения. Двадцать локаций, всё видно сразу, у каждой три числа: ярус, ставка, богатство.
  • Кланы диегетичны и не тикают. Состояние — чистая функция; в сохранении живут только дельты игрока.
  • Конкуренция — за ресурс, а не с игроком. Клан истощает локацию, но никогда не отнимает добычу и не нападает.

Требует проверки

  • Числа истощения (3 / −1 / +1 за 2 ч). Проверяются условием «три локации с богатством ≥ 2» на прогоне суток без игрока.
  • Ритм смены локаций кланами — 40 минут выбрано под сессию, а не замерено.
  • Штраф ×0,4 на выработанной локации. Слишком мягкий — карта не нужна; слишком жёсткий — карта запрещает играть.

Проверяем замером

  • Доля сессий, где игрок сменил локацию после первой вылазки. Ниже трети — сравнивать нечего, карта декоративна.
  • Доля заходов в выработанные локации. Высокая — штраф не читается до входа, то есть экран врёт.
  • Возвращаемость на второй день у видевших карту против не видевших: карта обязана оправдать своё появление именно удержанием.

Главный вопрос документа: появляется ли у игрока привычка смотреть карту перед вылазкой. Если он всегда ходит в ближайшую локацию — мир не работает, и никакой онлайн этого не исправит.
